### Исправлено

## Версия 1.0.15 (2024-12-18)

### Добавлено

- Компонент `BackendStatus` для отслеживания доступности backend
- Автоматическая проверка `/api/health` каждые 30 секунд

## Версия 1.0.14 (2024-12-18)

### Добавлено

- Миграция настроек админ-панели в PostgreSQL
- Таблица `admin_settings` для хранения настроек
- API endpoints для управления настройками:
  - `GET /api/admin/settings` — получить настройки
  - `PUT /api/admin/settings` — обновить настройки
  - `POST /api/admin/settings/reset` — сбросить настройки
  - `POST /api/admin/settings/validate` — проверить учётные данные
  - `GET /api/admin/settings/has-credentials` — проверить наличие учётных данных

### Изменено

- Убран localStorage для хранения настроек админ-панели
- Все настройки теперь хранятся в PostgreSQL
- Frontend загружает настройки через API

---

## Версия 1.0.13 (2024-12-18)

### Добавлено

- Миграция истории загрузок в PostgreSQL
- Таблицы `session_files` и `session_texts`
- API endpoints для управления историей:
  - `GET /api/session/history` — получить историю
  - `POST /api/session/history/file` — добавить файл
  - `POST /api/session/history/text` — добавить текст
  - `DELETE /api/session/history/file/:shortUrl` — удалить файл
  - `DELETE /api/session/history/text/:shortUrl` — удалить текст
  - `DELETE /api/session/history` — очистить историю

### Изменено

- Убран localStorage для хранения истории загрузок
- История теперь синхронизируется между устройствами
- Frontend загружает историю через API
