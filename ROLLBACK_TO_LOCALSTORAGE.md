# 🔄 Откат проекта на версию с localStorage

## 📅 Дата отката
Проект откатан на момент использования localStorage для хранения истории сессий.

## 🎯 Что это значит

### Архитектура хранения
```
Cookie (session_id) → localStorage (история) ✅
```

### Где хранятся данные

#### Cookie (браузер)
- ✅ `fileshare_session_id` — ID сессии
- ✅ Срок жизни настраивается в админке

#### localStorage (браузер)
- ✅ История загрузок файлов
- ✅ История загрузок текстов
- ✅ Настройки админки

#### Сервер (PostgreSQL)
- ❌ НЕ используется для истории сессий
- ✅ Только для метаданных файлов и текстов

## 📊 Структура проекта

```
src/
├── components/
│   ├── FileUpload.tsx          # Загрузка файлов
│   └── ExpirationSelector.tsx  # Выбор срока хранения
├── pages/
│   ├── HomePage.tsx            # Главная страница
│   ├── ShareView.tsx           # Просмотр файла
│   └── AdminPanel.tsx          # Админ-панель
├── services/
│   ├── adminService.ts         # Настройки (localStorage)
│   └── sessionService.ts       # Сессии (cookie + localStorage)
└── App.tsx                     # Роутинг
```

## 🔑 Ключевые файлы

### sessionService.ts
- Управление сессиями через cookie
- История хранится в localStorage
- Функции:
  - `getCurrentSession()` — получить/создать сессию
  - `getSessionHistory()` — получить историю
  - `addFileToHistory()` — добавить файл в историю
  - `addTextToHistory()` — добавить текст в историю
  - `removeFileFromHistory()` — удалить файл из истории
  - `removeTextFromHistory()` — удалить текст из истории
  - `clearSessionHistory()` — очистить историю
  - `destroySession()` — завершить сессию

### adminService.ts
- Настройки админки в localStorage
- Функции:
  - `getAdminSettings()` — получить настройки
  - `saveAdminSettings()` — сохранить настройки
  - `resetAdminSettings()` — сбросить настройки

## 💡 Преимущества этой версии

### Простота
- ✅ Не нужен backend для истории сессий
- ✅ Не нужны миграции БД
- ✅ Всё работает на клиенте

### Скорость
- ✅ Мгновенный доступ к истории
- ✅ Нет сетевых запросов для истории
- ✅ Работает офлайн

### Приватность
- ✅ История не покидает браузер
- ✅ Нет данных на сервере
- ✅ Пользователь контролирует данные

## ⚠️ Ограничения

### Синхронизация
- ❌ История не синхронизируется между устройствами
- ❌ При смене браузера история теряется
- ❌ При очистке браузера история удаляется

### Надёжность
- ⚠️ localStorage может быть очищен пользователем
- ⚠️ Нет резервного копирования
- ⚠️ Ограниченный размер (5-10 MB)

## 🧪 Тестирование

### Тест 1: Создание сессии
```
1. Откройте сайт в новом браузере
2. Откройте консоль (F12)
3. Проверьте cookie:
   - Application → Cookies → fileshare_session_id
4. Проверьте localStorage:
   - Application → Local Storage → fileshare_session_history
5. Должна быть создана новая сессия
```

### Тест 2: Восстановление сессии
```
1. Загрузите файл
2. Закройте браузер
3. Откройте браузер снова
4. Перейдите на сайт
5. История загрузок должна восстановиться
```

### Тест 3: Истечение сессии
```
1. В админке установите срок жизни сессии: 1 день
2. Загрузите файл
3. Подождите 1 день (или измените время в cookie)
4. Откройте сайт снова
5. Должна создаться новая сессия
6. История загрузок должна быть пустой
```
