# ⚡ Быстрое создание учётных данных администратора

## 🎯 Что нужно сделать

После установки FileShare учётные данные администратора создаются при первом входе в админ-панель.

## 🚀 Пошаговая инструкция

### 1. Откройте секретный URL

Перейдите по URL, который был показан в конце установки:

```
https://fileshare.local/#/my-secret-admin-2024
```

### 2. Создайте учётные данные

Увидите форму первичной настройки:

- **Логин**: минимум 3 символа (буквы, цифры, дефис, подчёркивание)
- **Пароль**: минимум 12 символов
  - Строчные буквы (a-z)
  - Заглавные буквы (A-Z)
  - Цифры (0-9)
  - Спецсимволы (!@#$%^&* и др.)

### 3. Сохраните учётные данные

**Важно!** Сохраните логин и пароль в безопасном месте (менеджер паролей).

### 4. Войдите в админ-панель

После создания учётных данных:
1. Введите логин и пароль
2. Нажмите "Войти"
3. Попадёте в админ-панель

## 🔄 Если забыли пароль

### Сброс через консоль браузера

1. Откройте сайт в браузере
2. Нажмите F12 (консоль разработчика)
3. Перейдите на вкладку "Console"
4. Выполните:

```javascript
localStorage.removeItem('fileshare_admin_settings');
```

5. Перезагрузите страницу
6. Перейдите по секретному URL
7. Создайте новые учётные данные
