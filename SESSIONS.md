# 🔐 Система сессий пользователей

## 🎯 Что это?

Система сессий позволяет привязывать историю загрузок к конкретному пользователю через cookie. Это решает проблему потери истории при закрытии браузера.

## 🔄 Как это работает?

### 1. Создание сессии

Когда пользователь впервые заходит на сайт:

```
1. Проверяем cookie "fileshare_session_id"
   ↓
2. Если cookie нет:
   - Генерируем уникальный ID сессии
   - Создаём cookie с сроком жизни (настраивается в админке)
   - Сохраняем сессию в localStorage
   - Инициализируем пустую историю загрузок
```

### 2. Восстановление сессии

При повторном посещении:

```
1. Читаем cookie "fileshare_session_id"
   ↓
2. Загружаем сессию из localStorage
   ↓
3. Проверяем срок действия
   ↓
4. Если сессия действительна:
   - Восстанавливаем историю загрузок
   - Пользователь видит свои файлы
```

### 3. Истечение сессии

Когда cookie истекает:

```
1. Cookie удаляется браузером
   ↓
2. При следующем посещении:
   - Создаётся новая сессия
   - История загрузок очищается
   - Файлы на сервере остаются (живут согласно сроку хранения)
```

## 💾 Где хранятся данные?

### Cookie (браузер)
```
fileshare_session_id=sess_lx7k9m2_a7b9c3d
expires: 2024-12-25T12:00:00Z
```

### localStorage (браузер)
```javascript
// Сессия
localStorage.getItem('session_sess_lx7k9m2_a7b9c3d')
// {
//   "id": "sess_lx7k9m2_a7b9c3d",
//   "createdAt": "2024-12-18T12:00:00Z",
//   "expiresAt": "2024-12-25T12:00:00Z"
// }

// История загрузок
localStorage.getItem('fileshare_session_history')
// {
//   "sessionId": "sess_lx7k9m2_a7b9c3d",
//   "files": [
//     {
//       "shortUrl": "abc123",
//       "name": "document.pdf",
//       "size": 1048576,
//       "uploadedAt": "2024-12-18T12:00:00Z",
//       "expiresAt": "2024-12-25T12:00:00Z"
//     }
//   ],
//   "texts": []
// }
```

### Сервер (PostgreSQL + файловое хранилище)
```
Файлы хранятся независимо от сессий!
- /dataStore/files/1789064440281-a7b9c3d-document.pdf
- Метаданные в таблице files
- Срок хранения определяется при загрузке
```

## ⚙️ Настройка в админке

### Срок жизни сессии

В админ-панели можно настроить срок жизни сессии:

```
Настройки админ-панели
├── Максимальный размер файла: 100MB
├── Минимальный срок хранения: 1 день
├── Максимальный срок хранения: 30 дней
├── Срок хранения по умолчанию: 7 дней
├── Кнопки срока хранения: 1, 3, 7, 14, 30
└── Срок жизни сессии: 7 дней  ← НОВОЕ!
```

**Рекомендации:**
- **1 день** — для публичных компьютеров
- **7 дней** — стандартное значение
- **30 дней** — для постоянных пользователей
- **365 дней** — практически бессрочная сессия

## 🔒 Безопасность

### Что защищено?
- ✅ Cookie передаётся только по HTTPS
- ✅ Cookie имеет флаг `SameSite=Strict` (защита от CSRF)
- ✅ ID сессии генерируется случайно
- ✅ Сессия привязана к конкретному браузеру

### Что НЕ защищено?
- ⚠️ Cookie можно очистить вручную
- ⚠️ Режим инкогнито не сохраняет cookie
- ⚠️ Нет аутентификации (логин/пароль) для пользователей

### Рекомендации
- Используйте HTTPS (уже настроено)
- Настройте разумный срок жизни сессии (7 дней)
- Для критичных данных используйте аутентификацию

## 🧪 Тестирование

### Тест 1: Создание сессии
```
1. Откройте сайт в новом браузере
2. Откройте консоль (F12)
3. Проверьте cookie:
   - Application → Cookies → fileshare_session_id
4. Проверьте localStorage:
   - Application → Local Storage → session_*
5. Должна быть создана новая сессия
```

### Тест 2: Восстановление сессии
```
1. Загрузите файл
2. Закройте браузер
3. Откройте браузер снова
4. Перейдите на сайт
5. История загрузок должна восстановиться
```

### Тест 3: Истечение сессии
```
1. В админке установите срок жизни сессии: 1 день
2. Загрузите файл
3. Подождите 1 день (или измените время в cookie)
4. Откройте сайт снова
5. Должна создаться новая сессия
6. История загрузок должна быть пустой
```

### Тест 4: Файлы живут независимо от сессии
```
1. Загрузите файл со сроком хранения 30 дней
2. Дождитесь истечения сессии (7 дней)
3. Создаётся новая сессия
4. Файл всё ещё доступен по ссылке /s/abc123
5. Файл будет удалён через 30 дней (срок хранения)
```

## 💡 Преимущества

### Для пользователей
- ✅ История загрузок сохраняется между посещениями
- ✅ Можно управлять своей историей (удалять файлы)
- ✅ Не нужно регистрироваться
- ✅ Анонимность сохраняется

### Для администраторов
- ✅ Настраиваемый срок жизни сессии
- ✅ Простая реализация (cookie + localStorage)
- ✅ Не нужна база данных для сессий
- ✅ Минимальная нагрузка на сервер

## 🔄 Отличия от полной аутентификации

| Аспект | Сессии (cookie) | Полная аутентификация |
|--------|-----------------|----------------------|
| Регистрация | ❌ Не нужна | ✅ Нужна |
| Логин/пароль | ❌ Нет | ✅ Есть |
| Привязка к пользователю | ⚠️ Слабая (cookie) | ✅ Сильная (аккаунт) |
| Анонимность | ✅ Полная | ❌ Нет |
| Надёжность | ⚠️ Cookie можно очистить | ✅ Аккаунт сохраняется |
| Сложность реализации | ✅ Простая | ❌ Сложная |

## 📚 API сессий

### `getCurrentSession()`
Получить текущую сессию или создать новую.

```typescript
const session = getCurrentSession();
console.log(session.id); // "sess_lx7k9m2_a7b9c3d"
console.log(session.expiresAt); // "2024-12-25T12:00:00Z"
```

### `getSessionHistory()`
Получить историю загрузок текущей сессии.

```typescript
const history = getSessionHistory();
console.log(history.files); // [{ shortUrl, name, size, ... }]
console.log(history.texts); // [{ shortUrl, title, ... }]
```

### `addFileToHistory(file)`
Добавить файл в историю сессии.

```typescript
addFileToHistory({
  shortUrl: 'abc123',
  name: 'document.pdf',
  size: 1048576,
  expiresAt: '2024-12-25T12:00:00Z',
});
```

### `removeFileFromHistory(shortUrl)`
Удалить файл из истории сессии.

```typescript
removeFileFromHistory('abc123');
```

### `destroySession()`
Завершить сессию (удалить cookie и данные).

```typescript
destroySession();
```
