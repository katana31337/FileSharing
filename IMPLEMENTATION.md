## 🔄 Поток данных

### Загрузка файла
```
1. Пользователь выбирает файл
   ↓
2. Frontend проверяет размер (из настроек)
   ↓
3. Frontend отправляет POST /api/files
   ↓
4. Backend сохраняет файл в /dataStore/files/
   ↓
5. Backend сохраняет метаданные в PostgreSQL
   ↓
6. Backend возвращает shortUrl
   ↓
7. Frontend добавляет файл в историю сессии
   ↓
8. Пользователь получает ссылку: https://domain/#/s/abc123
```

### Скачивание файла
```
1. Пользователь открывает ссылку: https://domain/#/s/abc123
   ↓
2. Frontend отправляет GET /api/files/abc123
   ↓
3. Backend проверяет срок хранения
   ↓
4. Backend возвращает файл из /dataStore/files/
   ↓
5. Frontend показывает файл пользователю
```

### Система сессий
```
1. Пользователь заходит на сайт
   ↓
2. Frontend проверяет cookie fileshare_session_id
   ↓
3. Если cookie есть:
   - Загружает сессию из localStorage
   - Проверяет срок действия
   - Если сессия действительна → восстанавливает историю
   - Если сессия истекла → создаёт новую сессию
   ↓
4. Если cookie нет:
   - Создаёт новую сессию
   - Сохраняет в cookie и localStorage
   ↓
5. При загрузке файла:
   - Добавляет в историю сессии
   - История сохраняется в localStorage
   ↓
6. При повторном визите:
   - Сессия восстанавливается из cookie
   - История загрузок отображается
```

## 🎨 Компоненты

### Frontend
- `HomePage` — главная страница с загрузкой файлов
- `ShareView` — просмотр/скачивание файла по ссылке
- `AdminPanel` — админ-панель с настройками
- `FileUpload` — компонент загрузки файлов
- `ExpirationSelector` — выбор срока хранения

### Backend
- `FileController` — обработка запросов файлов
- `TextController` — обработка запросов текстов
- `AdminSettingsController` — управление настройками
- `FileService` — бизнес-логика файлов
- `TextService` — бизнес-логика текстов
- `AdminSettingsService` — бизнес-логика настроек

## 🔧 Конфигурация

```env
DOMAIN=fileshare.local
DB_USER=fileshare
DB_PASSWORD=secret
DB_NAME=fileshare
SSL_TYPE=selfsigned
```

### Настройки админки (localStorage)
```javascript
{
  maxFileSize: 104857600,        // 100 MB
  minExpirationDays: 1,
  maxExpirationDays: 30,
  defaultExpirationDays: 7,
  expirationButtons: [1, 3, 7, 14, 30],
  sessionDurationDays: 7,
  adminLogin: 'admin',
  adminPassword: 'SecurePass123!',
  adminSecretPath: 'secret-admin',
  logo: '',
  logoType: 'none'
}
```

```javascript
// Cookie
fileshare_session_id=sess_lx7k9m2_a7b9c3d

  "createdAt": "2024-12-18T12:00:00Z",
  "expiresAt": "2024-12-25T12:00:00Z"

```

## 🎯 Ключевые особенности

1. **Полная интеграция frontend-backend**
   - Настройки применяются мгновенно
   - Ошибки отображаются красиво
   - Сессии синхронизированы

2. **Гибкая настройка**
   - Все параметры настраиваются через админку
   - Не нужно перезапускать сервисы
   - Настройки сохраняются в БД

3. **Безопасность**
   - HTTPS из коробки
   - Секретный URL для админки
   - Валидация пароля
   - Защита от CSRF

4. **Масштабируемость**
   - Docker для деплоя
   - PostgreSQL для данных
   - Файловое хранилище для файлов
   - Можно легко добавить S3

5. **UX**
   - История загрузок
   - Красивые ошибки
   - Настраиваемые кнопки
   - Информация о сессии
