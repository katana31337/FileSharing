# ⚡ Быстрая настройка сессий

## Что это?

Система сессий сохраняет историю загрузок в cookie браузера. Пользователь может закрыть браузер и вернуться позже — его файлы будут в истории.

## Как работает?

1. **Первый визит** → создаётся сессия (cookie на 7 дней)
2. **Загрузка файла** → добавляется в историю сессии
3. **Повторный визит** → сессия восстанавливается из cookie
4. **Через 7 дней** → cookie истекает, создаётся новая сессия

## Настройка срока жизни сессии

В админ-панели:
```
Срок жизни сессии (дни): [7]
```

**Рекомендации:**
- `1` — для публичных компьютеров
- `7` — стандартное значение
- `30` — для постоянных пользователей

## Что видит пользователь?

### Информация о сессии
```
Сессия: sess_lx7k9m2_a7b9c3d...
Истекает: 25.12.2024
Загружено файлов: 3
```

### История загрузок
```
История загрузок
├── document.pdf (загружен 18.12.2024)
├── image.png (загружен 19.12.2024)
└── archive.zip (загружен 20.12.2024)
```

## Проверка работы

### Тест 1: Создание сессии
```
1. Откройте сайт в новом браузере
2. F12 → Application → Cookies
3. Должен быть cookie: fileshare_session_id
```

### Тест 2: Восстановление сессии
```
1. Загрузите файл
2. Закройте браузер
3. Откройте браузер снова
4. История загрузок должна восстановиться
```

### Тест 3: Истечение сессии
```
1. Установите срок жизни сессии: 1 день
2. Загрузите файл
3. Подождите 1 день
4. Откройте сайт снова
5. Должна создаться новая сессия
```

## Важно!

- ✅ Файлы на сервере живут согласно сроку хранения (не сессии)
- ✅ Cookie можно очистить вручную (история потеряется)
- ✅ Режим инкогнито не сохраняет cookie
- ✅ Файлы доступны по ссылке даже после истечения сессии
