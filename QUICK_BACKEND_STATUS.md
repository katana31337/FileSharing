# ⚡ Быстрая настройка мониторинга backend

## Что это?

Компонент `BackendStatus` автоматически проверяет доступность backend и показывает предупреждение пользователю, если сервер недоступен.

## Как работает?

1. **При загрузке страницы** → проверяет `GET /api/health`
2. **Если backend доступен** → ничего не показывает
3. **Если backend недоступен** → показывает красное предупреждение
4. **Повторяет проверку** каждые 30 секунд

## Что видит пользователь?

### Backend доступен
```
(ничего не показывается)
```

### Backend недоступен
```
┌─────────────────────────────────────────┐
│ ⚠️ Сервер недоступен                    │
│                                         │
│ База данных временно недоступна.        │
│ Функционал загрузки файлов и просмотра  │
│ истории не работает.                    │
│                                    [✕]  │
└─────────────────────────────────────────┘
```

## Настройки

- **Таймаут проверки:** 5 секунд
- **Интервал проверки:** 30 секунд
- **Позиция:** верх страницы, по центру

## Тестирование

### Тест 1: Backend доступен
```bash
# Запустите backend
npm run dev

# Откройте сайт
# Должно появиться "Проверка подключения..."
# Через 1-2 секунды предупреждение исчезнет
```

### Тест 2: Backend недоступен
```bash
# Остановите backend
# Откройте сайт
# Должно появиться красное предупреждение
```
