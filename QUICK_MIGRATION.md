# ⚡ Быстрая миграция на PostgreSQL

## Что изменилось?

История загрузок теперь хранится в PostgreSQL вместо localStorage.

**Было:** Cookie → localStorage ❌  
**Стало:** Cookie → PostgreSQL ✅

## Преимущества

- ✅ История синхронизируется между устройствами
- ✅ Не теряется при очистке браузера
- ✅ Надёжное хранение в БД
- ✅ Резервное копирование через бэкап БД

## Установка

### 1. Применить миграцию
```bash
cd server
psql -U fileshare -d fileshare -f migrations/003_session_history.sql
```

### 2. Установить зависимости backend
```bash
cd server
npm install
```

### 3. Запустить backend
```bash
npm run dev
```

### 4. Запустить frontend
```bash
npm run dev
```

## Проверка

### Тест 1: Загрузка файла
```
1. Откройте сайт
2. Загрузите файл
3. Проверьте PostgreSQL:
   SELECT * FROM session_files;
4. Должна быть запись
```

### Тест 2: Повторный визит
```
1. Загрузите файл
2. Закройте браузер
3. Откройте браузер снова
4. История должна восстановиться из БД
```
