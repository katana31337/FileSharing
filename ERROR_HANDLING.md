# 🔔 Обработка ошибок

## 🎯 Что было исправлено

Раньше при ошибке backend (например, отсутствие колонки в БД) frontend молча переключался на localStorage, и пользователю казалось, что файл загружен, но на сервере он не сохранялся.

Теперь:
- ✅ Backend возвращает информативные ошибки с деталями
- ✅ Frontend показывает ошибки пользователю через toast-уведомления
- ✅ Frontend НЕ переключается на localStorage при ошибке загрузки
- ✅ Пользователь видит конкретную проблему

## 📊 Типы ошибок

### Backend ошибки

| Код | Сообщение | Описание |
|-----|-----------|----------|
| 400 | Неверные параметры | Ошибка валидации (например, срок хранения) |
| 404 | Файл не найден | Файл не существует или срок истёк |
| 500 | Ошибка базы данных | Проблема со схемой БД |
| 500 | Ошибка доступа к хранилищу | Нет прав на запись файлов |
| 507 | Недостаточно места | Закончилось место на сервере |

### Frontend обработка

```typescript
try {
  const item = await saveFile(file, options, onProgress);
  // Успешная загрузка
} catch (error) {
  if (error instanceof ApiError) {
    // Показываем ошибку пользователю
    toast.error('Ошибка загрузки файла', `${file.name}: ${error.message}`);
    
    // Если есть детали от backend
    if (error.details) {
      console.error('Детали ошибки:', error.details);
    }
  }
}
```

## 🔍 Примеры ошибок

### Ошибка 1: Отсутствие колонки в БД

**Backend лог:**
```
[PostgresFileRepository] ❌ Ошибка создания записи в БД: error: column "name" of relation "files" does not exist
```

**Frontend toast:**
```
❌ Ошибка загрузки файла
"document.pdf": Ошибка базы данных: Схема базы данных не соответствует ожидаемой. Обратитесь к администратору.
```

**Решение:**
```bash
sudo bash fix-db-schema.sh
```

### Ошибка 2: Нет прав на запись

**Backend лог:**
```
[LocalStorageProvider] ❌ Ошибка записи файла: Error: EACCES: permission denied, mkdir '/app/uploads/files'
```

**Frontend toast:**
```
❌ Ошибка загрузки файла
"document.pdf": Ошибка доступа к хранилищу: Нет прав для записи файлов. Обратитесь к администратору.
```

**Решение:**
```bash
sudo chmod 777 /dataStore/files/
```

### Ошибка 3: Недостаточно места

**Backend лог:**
```
[LocalStorageProvider] ❌ Ошибка записи файла: Error: ENOSPC: no space left on device
```

**Frontend toast:**
```
❌ Ошибка загрузки файла
"document.pdf": Недостаточно места: На сервере закончилось свободное место. Обратитесь к администратору.
```

**Решение:**
```bash
# Проверить свободное место
df -h /dataStore

# Удалить старые файлы
find /dataStore/files -type f -mtime +30 -delete
```

## 🎨 Toast уведомления

### Типы уведомлений

- 🔴 **Error** (красный) — критические ошибки
- 🟡 **Warning** (жёлтый) — предупреждения
- 🔵 **Info** (синий) — информационные сообщения
- 🟢 **Success** (зелёный) — успешные операции

### Примеры использования

```typescript
// Ошибка
toast.error('Ошибка загрузки файла', `"${file.name}": ${errorMessage}`);

// Предупреждение (частичная загрузка)
toast.warning('Частичная загрузка', `Успешно: ${successCount}, ошибок: ${errorCount}`);

// Успех
toast.success('Файл загружен', `"${file.name}" успешно загружен`);

// Информация
toast.info('Загрузка', `Загрузка файла: ${file.name}`);
```

## 📋 Что делать при ошибках

### Для пользователя

1. **Прочитайте сообщение об ошибке** — оно содержит конкретную проблему
2. **Обратитесь к администратору** — если ошибка на стороне сервера
3. **Попробуйте ещё раз** — если ошибка временная

### Для администратора

1. **Проверьте логи backend:**
   ```bash
   docker compose logs -f backend
   ```

2. **Проверьте состояние системы:**
   ```bash
   sudo bash full-diagnose.sh
   ```

3. **Проверьте свободное место:**
   ```bash
   df -h /dataStore
   ```

4. **Проверьте права доступа:**
   ```bash
   ls -la /dataStore/files/
   ```

## 💡 Лучшие практики

### Backend

```typescript
// ✅ Хорошо: информативная ошибка
throw new Error('Срок хранения должен быть от 1 до 30 дней');

// ❌ Плохо: неинформативная ошибка
throw new Error('Invalid input');
```

### Frontend

```typescript
// ✅ Хорошо: показывать ошибку пользователю
catch (error) {
  toast.error('Ошибка загрузки', error.message);
  throw error; // Пробрасываем дальше
}

// ❌ Плохо: молча переключаться на localStorage
catch (error) {
  useApi = false;
  return saveFileLocal(file); // Пользователь не узнает о проблеме
}
```
