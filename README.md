## 🎯 О проекте

FileShare — это современный сервис для обмена файлами с короткими ссылками. Позволяет загружать файлы, получать короткие ссылки и делиться ими с другими пользователями.

**Ключевые особенности:**
- Все данные хранятся в PostgreSQL
- Файлы хранятся в `/dataStore/files/`
- История загрузок синхронизируется между устройствами
- Настройки админ-панели централизованы в БД
- Автоматическая очистка файлов по истечении срока хранения

## 🔄 Как это работает

### Загрузка файла

1. Пользователь выбирает файл на главной странице
2. Frontend проверяет размер файла (из настроек админки)
3. Frontend отправляет `POST /api/files` на backend
4. Backend сохраняет файл в `/dataStore/files/` с уникальным именем
5. Backend сохраняет метаданные в PostgreSQL (таблица `files`)
6. Backend возвращает `shortUrl`
7. Frontend добавляет файл в историю сессии через `POST /api/session/history/file`
8. Пользователь получает ссылку: `https://domain/#/s/abc123`

### Скачивание файла

1. Пользователь открывает ссылку: `https://domain/#/s/abc123`
2. Frontend отправляет `GET /api/files/abc123`
3. Backend проверяет срок хранения
4. Backend возвращает файл из `/dataStore/files/`
5. Frontend показывает файл пользователю

### Система сессий

1. Пользователь заходит на сайт
2. Frontend проверяет cookie `fileshare_session_id`
3. Если cookie есть → загружает сессию из БД
4. Если cookie нет → создаёт новую сессию
5. При загрузке файла → добавляет в историю сессии
6. При повторном визите → история восстанавливается из БД
7. Через N дней → cookie истекает, создаётся новая сессия

## 🚀 Установка

### Автоматическая установка (рекомендуется)

```bash
# Один командой
curl -sSL https://raw.githubusercontent.com/katana31337/FileSharing/main/install.sh | sudo bash

# Или скачайте и запустите
wget https://raw.githubusercontent.com/katana31337/FileSharing/main/install.sh
chmod +x install.sh
sudo bash install.sh
```

Скрипт автоматически:
- ✅ Проверит зависимости (Docker, Docker Compose, OpenSSL)
- ✅ Спросит тип SSL сертификата (Let's Encrypt или Self-signed)
- ✅ Спросит домен/IP адрес
- ✅ Сгенерирует безопасные пароли для базы данных
- ✅ Спросит секретный путь для админ-панели
- ✅ Создаст конфигурационные файлы (docker-compose.yml, nginx.conf, .env)
- ✅ Получит SSL сертификат
- ✅ Запустит все сервисы

### Ручная установка

```bash
# Клонировать репозиторий
git clone https://github.com/katana31337/FileSharing.git
cd FileSharing

# Установить зависимости
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build
```

### Первый вход в админ-панель

1. Откройте секретный URL (указан в конце установки)
2. Создайте логин и пароль
3. Войдите в админ-панель
4. Настройте параметры по необходимости

## 🐳 Публикация на Docker Hub

### Подготовка

1. Создайте аккаунт на [Docker Hub](https://hub.docker.com/signup)
2. Войдите в Docker Hub из CLI:
   ```bash
   docker login
   ```

### Публикация образов

```bash
# Запустить скрипт публикации (замените yourusername на ваш логин Docker Hub)
sudo bash publish-docker.sh yourusername 1.0.16
```

Скрипт автоматически:
- ✅ Соберёт frontend образ
- ✅ Соберёт backend образ
- ✅ Опубликует образы на Docker Hub

### Обновление на сервере

```bash
# Перейти в директорию установки
cd /opt/fileshare

# Обновить образы
docker compose pull

# Перезапустить контейнеры
docker compose up -d
```

### CI/CD с GitHub Actions

При создании тега в GitHub автоматически запускается публикация:

```bash
git tag v1.0.16
git push origin v1.0.16
```

GitHub Actions автоматически:
- ✅ Соберёт образы
- ✅ Опубликует на Docker Hub
- ✅ Создаст релиз на GitHub
