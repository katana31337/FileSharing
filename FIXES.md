# 🔧 Исправления проблем с админ-панелью и загрузкой файлов

## 🐛 Исправленные проблемы

### 1. Настройки размера файла не применялись к главной странице

**Проблема:** В админке можно было задать максимальный размер файла 1000 MB, но на главной странице всё равно отображалось "Максимум 100 МБ на файл".

**Причина:** Компонент FileUpload использовал захардкоженное значение вместо получения настроек из `adminService`.

**Решение:**
- Компонент `FileUpload` теперь получает настройки через `getAdminSettings()`
- Отображаемый максимальный размер берётся из `settings.maxFileSize`
- Проверка размера файла также использует настройки из `adminService`

**Код:**
```typescript
const settings = getAdminSettings();

// Отображение
<p className="text-sm text-gray-500">
  Максимум {formatFileSize(settings.maxFileSize)}
</p>

// Проверка
if (file.size > settings.maxFileSize) {
  // Ошибка
}
```

### 2. Некрасивая ошибка при превышении размера файла

**Проблема:** При загрузке файла больше максимального размера появлялась страшная ошибка "Ошибка загрузки файла" без понятного объяснения.

**Решение:**
- Создан красивый блок ошибки с иконкой `AlertCircle`
- Ошибка показывает конкретные значения: размер файла и максимальный размер
- Сообщение на русском языке с понятным объяснением
- Кнопка закрытия ошибки

**Пример сообщения:**
```
Не удалось загрузить файл

Размер файла: 150.5 MB
Максимальный размер: 100 MB

Пожалуйста, выберите файл меньшего размера.
```

**Код:**
```typescript
if (file.size > settings.maxFileSize) {
  const maxSizeFormatted = formatFileSize(settings.maxFileSize);
  const fileSizeFormatted = formatFileSize(file.size);
  setError(
    `Файл слишком большой\n\n` +
    `Размер файла: ${fileSizeFormatted}\n` +
    `Максимальный размер: ${maxSizeFormatted}\n\n` +
    `Пожалуйста, выберите файл меньшего размера.`
  );
}
```

### 3. Непонятное сообщение "Проверьте логи для деталей"

**Проблема:** Появлялось сообщение "Не удалось загрузить файлы. Ошибок: 1. Проверьте логи для деталей", но не было понятно, где смотреть логи.

**Решение:**
- Убрано упоминание логов из пользовательского интерфейса
- Все ошибки теперь показываются напрямую в интерфейсе
- Логи остаются только в консоли браузера (F12) для разработчиков
- Пользователь видит конкретную причину ошибки сразу

### 4. Кнопки срока хранения не соответствовали настройкам

**Проблема:** Если в админке задать максимум 10 дней, то на главной странице показывались только кнопки "1 день", "3 дня", "7 дней", но не было кнопки "10 дней".

**Причина:** Кнопки срока хранения были захардкожены в компоненте.

**Решение:**
- Добавлено новое поле `expirationButtons` в `AdminSettings`
- Это массив чисел, определяющий значения кнопок
- По умолчанию: `[1, 3, 7, 14, 30]`
- В админке можно настроить любые значения через поле ввода

**Настройка в админке:**
```
Кнопки срока хранения (через запятую)
[1, 3, 7, 14, 30]
Укажите значения в днях через запятую
```

**Примеры:**
- `[1, 3, 7, 14, 30]` — стандартный набор
- `[1, 2, 5, 10]` — если максимум 10 дней
- `[7, 14, 30, 60, 90]` — для долгосрочного хранения

**Код компонента:**
```typescript
const settings = getAdminSettings();
const buttons = settings.expirationButtons;

return (
  <div className="flex flex-wrap gap-2">
    {buttons.map((days) => (
      <button key={days} onClick={() => onChange(days)}>
        {days} {days === 1 ? 'день' : days < 5 ? 'дня' : 'дней'}
      </button>
    ))}
  </div>
);
```

## 💡 Дополнительные улучшения

### 1. Валидация кнопок срока хранения

В админке добавлена проверка:
- Кнопки должны быть числами
- Значения должны быть больше 0
- Должна быть хотя бы одна кнопка

### 2. Форматирование размера файла

Функция `formatFileSize` корректно форматирует:
- Байты: "500 B"
- Килобайты: "1.5 KB"
- Мегабайты: "100 MB"
- Гигабайты: "1.5 GB"

### 3. Парсинг размера файла

Функция `parseFileSize` принимает:
- "100MB" → 104857600
- "1 GB" → 1073741824
- "500 KB" → 512000
- "1000 B" → 1000
