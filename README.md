# 📁 FileShare — Сервис обмена файлами

Клиент-серверное приложение для быстрого обмена файлами через короткие ссылки.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build
```

## 🎯 Исправленные проблемы

### 1. Настройки размера файла применяются к главной странице
✅ В админке задали 1000 MB → на главной показывается "Максимум 1000 MB"

### 2. Красивая ошибка при превышении размера
✅ Понятное сообщение с конкретными значениями вместо страшной ошибки

### 3. Убрано "Проверьте логи для деталей"
✅ Все ошибки показываются напрямую в интерфейсе

### 4. Настраиваемые кнопки срока хранения
✅ В админке можно задать любые значения кнопок через запятую

### 5. Система сессий с историей загрузок
✅ История загрузок сохраняется в cookie (настраиваемый срок жизни)
✅ При повторном визите история восстанавливается
✅ Файлы на сервере живут согласно сроку хранения (независимо от сессии)
